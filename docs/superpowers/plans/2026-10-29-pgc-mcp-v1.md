# PGC MCP Server V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local, read-only MCP server exposing 11 tools over the public `pgcgolf.club` REST API, usable from Claude Desktop / Claude Code over stdio.

**Architecture:** A plain Java application — no Spring. `main()` builds an `McpSyncServer` on `StdioServerTransportProvider`, registers 11 tool specifications in a deterministic order, and blocks. Each tool calls one public `/webapi/...` endpoint through a single `PgcApiClient`, then projects the response down to a few fields before returning it as text. All logging goes to stderr; stdout is the protocol channel.

**Tech Stack:** Java 21, Maven 3.9, `io.modelcontextprotocol.sdk:mcp:2.1.0` (pulls `mcp-core` + `mcp-json-jackson3`), JUnit 5, Mockito. No web framework, no database, no Spring.

**Spec:** `docs/superpowers/specs/2026-10-29-pgc-mcp-server-design.md`

## Global Constraints

- **New artifact.** `PGCMcp/` is a separate Maven project. It does not modify `PGCServer`. Group `club.pgcgolf`, artifact `pgc-mcp`, base package `club.pgcgolf.mcp`.
- **Java 21**, Maven 3.9.12 (both verified present locally).
- **Pin stable versions only:** `io.modelcontextprotocol.sdk:mcp:2.1.0`. Not 2.2.0-M1, not Spring AI.
- **Jackson 3, not 2.** The JSON classes live in `tools.jackson.*`. `com.fasterxml.jackson.*` imports are wrong here and will not compile against this SDK.
- **Nothing may be written to stdout.** On stdio, stdout *is* the JSON-RPC channel; a single `System.out.println` corrupts the stream. All diagnostics use `System.err`. No exceptions.
- **Read-only.** Tools issue HTTP GET only. No POST, PUT or DELETE, and no `/webapi/admin/**` path may appear anywhere in the codebase.
- **Strip PII unconditionally.** `phone` and `email` are removed from every player payload before it leaves the server. Not configurable.
- **Base URL** from env var `PGC_API_BASE_URL`, defaulting to `https://pgcgolf.club`.
- **Tool names** are `snake_case`; the 11 names and their arguments are fixed by spec §9 and must match exactly.
- **`tools/list` order is deterministic** — the registry returns tools in a fixed order, as the spec asks, so client and prompt caches can hit.

### Payload sizes measured against production 2026-10-29 — why projection is mandatory

| Endpoint | Raw | ≈ tokens |
|---|---|---|
| `/webapi/events` | 291 KB | **~73,000** |
| `/webapi/tournaments` | 116 KB | ~29,000 |
| `/webapi/rewards/all` | 85 KB | ~21,000 |
| `/webapi/points/game-scores` | 55 KB | ~14,000 |
| `/webapi/players` | 36 KB | ~9,000 |

`/webapi/events` and `/webapi/tournaments` eagerly nest `teeList`, and through it every tee and player score. **No tool may return an upstream body unprojected.** One unfiltered `list_events` would spend most of a context window on a single call.

## Review Focus

Five input classes the spec implies but which no tool's happy path exercises. Each has a test attached to the task that owns the code.

1. **A required argument is missing or null** — a model omits `playerId`. Expect a readable "missing required argument: playerId", not a `NullPointerException`. *(Task 3)*
2. **An argument arrives as the wrong JSON type** — `"1000"` as a string where a number is expected, which models do routinely. Expect coercion where unambiguous, a clear message otherwise. *(Task 3)*
3. **Upstream is unreachable, slow, or returns 5xx** — expect "the club API is unreachable (status 503)", never an empty result that a model will read as "no data exists". *(Task 2)*
4. **`find_player` matches nothing, or matches more than ten** — expect the no-match case to name the closest alternatives, and the over-ten case to say it truncated. A silent empty list makes a model assert the player does not exist. *(Task 4)*
5. **A valid entity with no child rows** — a player with no rounds, an event with no scores. Expect an explicit "no rounds recorded", distinguishable from a failure. *(Tasks 5, 6)*
